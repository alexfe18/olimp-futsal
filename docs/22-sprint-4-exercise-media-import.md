# Sprint 4.2.2 — Exercise Media Batch Import

Останнє оновлення: 2026-08-02

## Мета

Прибрати ручне відкриття кожної вправи під час додавання обкладинок і схем. Тренер або адміністратор завантажує один ZIP-пакет чи кілька зображень, перевіряє прив’язку за кодом вправи та підтверджує безпечне додавання або заміну.

## Маршрут

`/admin/coach/exercises/media-import`

Точка входу в меню:

`Робочий простір тренера → Імпорт медіа`

## Підтримувані файли

- один стандартний ZIP до 100 МБ;
- або до 200 окремих зображень;
- PNG, JPG, JPEG, WEBP;
- до 10 МБ на зображення;
- мінімальний розмір 320×180 px;
- максимальна сторона 12 000 px.

ZIP не повинен бути зашифрованим, багатотомним або ZIP64. Вкладені папки дозволені. Службові файли `__MACOSX`, `.DS_Store` та `._*` ігноруються.

## Правило іменування

```text
CODE-cover.png
CODE-diagram.png
```

Приклади:

```text
TECH-001-cover.png
TECH-001-diagram.png
WU-004-cover.webp
```

Код нормалізується до верхнього регістру та звіряється з полем `exercises.code`.

## Preview і статуси

Система показує:

- мініатюру;
- назву та розмір файла;
- код і назву знайденої вправи;
- тип медіа;
- статус перевірки.

Сводні фільтри:

- `Усього`;
- `Готові` — медіа цього типу ще немає;
- `Помилки` — неправильна назва, формат, розмір, дублікат у пакеті або відсутня вправа;
- `Заміни` — у вправи вже є обкладинка або схема.

## Стратегія заміни

За замовчуванням існуючі медіа пропускаються.

Під час вибору `Замінити після успішного завантаження`:

1. новий файл завантажується до bucket `exercise-media`;
2. відповідне поле вправи оновлюється новим storage path;
3. лише після успішного update старий файл видаляється зі Storage;
4. якщо update не вдався, новий файл видаляється як rollback;
5. якщо cleanup старого файла не вдався, нове медіа залишається активним, а у summary показується warning про orphan-файл.

## Поточна модель медіа

Поточна таблиця `exercises` підтримує:

- одну обкладинку — `cover_image_path`;
- одну схему — `diagram_image_path`.

Batch Import не створює окрему галерею схем і не змінює інші медіаполя.

## QA checklist

1. Завантажити коректний ZIP із новими обкладинками.
2. Перевірити `Усього / Готові / Помилки / Заміни`.
3. Перевірити thumbnail, code, title, dimensions і type.
4. Перевірити неправильну назву файла.
5. Перевірити невідомий код вправи.
6. Перевірити два `cover` для одного коду в одному пакеті.
7. Перевірити файл понад 10 МБ і замале зображення.
8. Перевірити стратегію `Пропустити`.
9. Перевірити стратегію `Замінити`.
10. Перевірити Library Card, Details Hero та Edit Preview після імпорту.
11. Перевірити, що імпорт cover не змінює diagram, і навпаки.
12. Перевірити ZIP із вкладеними папками та службовими файлами macOS.
