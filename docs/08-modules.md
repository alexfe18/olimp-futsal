# System Modules

> Functional Modules Documentation  
> Version: 1.0  
> Last updated: July 2026

---

# 1. Загальна інформація

Система **«Олімп Футзал»** побудована за модульним принципом.

Кожен модуль відповідає за окрему функціональність, має власний інтерфейс, структуру даних та бізнес-логіку.

Такий підхід дозволяє розширювати систему без зміни вже реалізованих компонентів.

---

# 2. Загальна структура модулів

```text
Public Website

├── News
├── Gallery

↓

Admin Panel

├── Players

├── Matches
├── Statistics
├── News

└── Push Notifications
```

# 3. Players Module

## Призначення

Управління гравцями клубу.

### Основні можливості

- створення гравця;
- редагування профілю;
- завантаження фотографії;
- номер;
- позиція;
- статус;
- активність.

### Використовується

- Attendance
- Match Statistics
- Push Notifications

---

# 4. Trainings Module

## Призначення

Керування тренуваннями.

### Основні можливості

- створення тренування;
- активація;
- редагування;
- скасування;
- перегляд майбутніх тренувань.

### Інтеграції

- Attendance
- Push Notifications
- PWA

---

# 5. Attendance Module

## Призначення

Контроль відвідуваності.

### Основні можливості

- відповіді гравців;
- фактична присутність;
- примітки тренера;
- історія відвідуваності.

### Бізнес-цінність

Дозволяє аналізувати дисципліну та активність команди.

---

# 7. Matches Module

# 8. Statistics Module

## Призначення

Статистика гравців.

### Основні показники

- матчі;
- голи;
- передачі;
- MVP;
- жовті картки;
- червоні картки;
- автоголи;
- сухі матчі воротаря.

### Автоматизація

Статистика оновлюється після внесення результатів матчу.

# 9. News Module

## Призначення

Публікація новин клубу.

### Основні можливості

- створення новини;
- завантаження обкладинки;
- короткий опис;
- повний текст;
- SEO-friendly slug;
- публікація.

### Public Pages

# 13. Admin Panel Module

## Призначення

Єдина точка керування системою.

### Доступні модулі

- Players
- Trainings
- Attendance
- Competitions
- Matches
- Statistics
- News
- Gallery

Адміністративна панель забезпечує централізоване управління всією системою.
