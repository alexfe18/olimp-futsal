# Sprint 03.5.5 — Exercise UI Localization Polish

## Мета

Усунути змішування української та англійської мов у модулі бібліотеки вправ.

## Реалізовано

- `pressing` → `Пресинг`;
- `full_team` → `Повний склад`;
- `custom` → `Власна`;
- `core` → `Базова`;
- `signature` → `Фірмова`;
- `community` → `Спільнота`;
- локалізовано службові підписи Coach Workspace, Edit/New Exercise, Exercise Preview і Training Builder;
- Preview форми показує локалізований формат гравців.

## Архітектурне правило

Значення enum у базі залишаються англомовними стабільними ключами. Відображення формується через словники локалізації. Англійська версія буде підключена окремим locale-шаром без одночасного змішування мов.
