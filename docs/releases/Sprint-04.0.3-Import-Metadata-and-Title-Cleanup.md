# Sprint 04.0.3 — Import Metadata and Title Cleanup

## Мета

Відокремити назву вправи від службової інформації про оновлення та показувати метадані імпорту у системному блоці сторінки вправи.

## Зміни

- Імпорт більше не зберігає тестовий суфікс `— ОНОВЛЕНО` у назві вправи.
- Суфікс очищається лише наприкінці назви та не впливає на звичайний текст усередині назви.
- Details завантажує колонку `source`.
- У блоці **Системна інформація → Історія** відображаються:
  - дата створення;
  - останнє оновлення з часом;
  - походження даних: імпорт або ручне створення;
  - джерело імпорту, якщо воно задане;
  - код та ID вправи.
- Додано одноразовий SQL cleanup для вже імпортованих QA-назв.

## Важливе рішення

Службові стани, дати та джерела не є частиною `title`. Назва вправи завжди залишається чистим користувацьким контентом.
