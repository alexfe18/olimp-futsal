# Sprint 04.0.2 — Exercise Import Summary Filters

Дата: 2026-08-02

## Цель

Сделать сводный блок предварительной проверки визуально единым с библиотекой упражнений и полезным при импорте больших файлов.

## Реализовано

- единый белый контейнер статистики с четырьмя элементами;
- фильтры `Усього`, `Готові`, `Помилки`, `Дублікати`;
- взаимоисключающая классификация строк;
- активное состояние выбранного фильтра;
- disabled-состояние для пустых групп;
- фильтрация таблицы без повторного чтения файла;
- подпись `Показано X із Y`;
- empty state при отсутствии строк в выбранной группе;
- отдельная отметка найденного дубликата;
- автоматический сброс на `Усього` для нового файла.

## Логика счётчиков

- `Готові`: валидные новые упражнения без совпадения по `code`;
- `Помилки`: строки хотя бы с одной ошибкой валидации;
- `Дублікати`: валидные строки, для которых найден существующий `code`;
- `Усього`: все строки выбранного файла.

## QA

1. Загрузить новый валидный файл — все строки должны попасть в `Готові`.
2. Повторно загрузить импортированный файл — строки должны попасть в `Дублікати`, а не в `Готові`.
3. Загрузить invalid-файл — строки должны попасть в `Помилки`.
4. Переключить все доступные фильтры и проверить таблицу.
5. Убедиться, что показатель с нулём недоступен.
6. Выбрать другой файл — активным снова становится `Усього`.
7. Проверить импорт при стратегиях skip и update.
