# Sprint 04.0 — Exercise Import Foundation

Дата: 2026-08-01

## Добавлено

- отдельный Import Workspace для Exercise Library;
- JSON/CSV parser без внешних зависимостей;
- скачиваемые шаблоны;
- preview-валидация по строкам;
- поиск дубликатов по `code`;
- стратегии skip/update;
- импорт упражнений, целей и тегов;
- progress и итоговый отчет.

## Безопасность данных

- строки с validation errors не импортируются;
- новая запись удаляется, если синхронизация целей или тегов завершилась ошибкой;
- обновляемая запись получает best-effort rollback;
- существующие media paths не изменяются при update-импорте.

## Ограничения v1

- импорт обложек, схем и видеофайлов не поддерживается;
- код упражнения обязателен и используется как идентификатор дубликата;
- английская локализация контента не входит в этот релиз.
