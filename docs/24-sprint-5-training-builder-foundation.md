# Sprint 05.0 — Training Builder Foundation

## Цель

Подключить Exercise Library к существующему модулю планов тренировок и получить минимальный рабочий конструктор тренировочной сессии.

## Маршруты

- `/admin/coach/training-plans` — список планов;
- `/admin/coach/training-plans/new` — создание черновика;
- `/admin/coach/training-plans/[id]` — повторное открытие и редактирование.

## Реализованный пользовательский поток

1. Тренер открывает создание новой сессии.
2. Заполняет название, дату, команду, возрастную группу, цель и заметки.
3. Выбирает один из двух способов наполнения плана: добавляет упражнение из Библиотеки или создаёт собственный блок вручную.
4. При необходимости сочетает оба типа блоков в одной тренировке.
5. Для собственного блока редактирует название, тип, описание, длительность и заметки.
6. При повторном добавлении того же библиотечного упражнения получает явное подтверждение.
7. Меняет порядок, длительность и заметки для каждого блока.
8. Видит автоматически рассчитанное общее время.
9. Сохраняет черновик одной транзакционной RPC-функцией.
10. Повторно открывает план и получает сохранённый порядок и значения.

## Архитектура UI

Общая форма вынесена в `TrainingPlanBuilder` и используется страницами Create и Edit.

Основные компоненты:

- `TrainingPlanBuilder.tsx` — метаданные, список блоков, сохранение и удаление;
- `ExerciseLibraryPicker.tsx` — поиск, фильтр категории и добавление упражнения;
- собственные блоки создаются и редактируются непосредственно в `TrainingPlanBuilder`;
- `training-plan-service.ts` — запросы к Supabase и mapping данных;
- `useTrainingPlanUnsavedChanges.ts` — защита незбережённых изменений;
- `types.ts` и `options.ts` — типы и локализационные словари.

## Изменения базы данных

Миграция: `sql/2026-08-02-training-builder-foundation.sql`.

### `training_plans`

Добавлены nullable-поля:

- `session_date date`;
- `team_name text`;
- `age_group text`.

Для старых планов `session_date` заполняется датой связанного `trainings.starts_at`, если `training_id` существует.

### `training_plan_blocks`

Добавлено:

- `exercise_id uuid null`;
- FK на `exercises.id` с `ON DELETE SET NULL`;
- индекс `(training_plan_id, sort_order)`;
- частичный индекс по `exercise_id`.

Название, описание, длительность и заметки остаются в блоке как snapshot. Поэтому план не теряет основную информацию, если упражнение позднее будет удалено.

## Транзакционное сохранение

`save_training_plan_draft(...)`:

- проверяет название, статус, интенсивность и JSON blocks;
- требует минимум один блок: библиотечный или созданный вручную;
- создаёт или обновляет `training_plans`;
- атомарно заменяет набор `training_plan_blocks`;
- сохраняет `exercise_id`, snapshot, длительность, порядок и заметки;
- пересчитывает `planned_duration`;
- возвращает ID плана.

Функция работает как `security invoker`, поэтому сохраняет действующие RLS-ограничения пользователя. Execute предоставлен ролям `authenticated` и `service_role`.

## Совместимость со старыми планами

- существующий `training_id` не удаляется и не перезаписывается;
- старые блоки без `exercise_id` загружаются как собственные блоки;
- их title, description, duration и notes сохраняются при следующем сохранении;
- старый или новый план может состоять только из собственных блоков, только из библиотечных упражнений либо сочетать оба типа.

## Защита данных

- выход со страницы при незбережённых изменениях требует подтверждения;
- сохранение выполняется одной RPC-транзакцией;
- при ошибке вставки удаление предыдущих блоков откатывается;
- удаление упражнения не удаляет блок тренировочного плана, а обнуляет только ссылку;
- удаление плана использует существующее каскадное удаление его блоков.

## Состояния интерфейса

Реализованы:

- loading состояния списка, Edit и библиотеки;
- empty state списка и пустой структуры;
- ошибки загрузки и сохранения;
- повторная загрузка;
- статус незбережённых изменений;
- сообщение об обязательной SQL-миграции при несовместимой схеме.

## Out of Scope

- календарь и RSVP;
- посещаемость;
- публикация плана игрокам;
- Session Review;
- шаблоны тренировок;
- micro/meso cycles;
- AI-генерация плана;
- Tactical Board и Video Library.
