# ⚽ Олімп Футзал — Club Management System

> Complete digital ecosystem for managing a futsal club.

---

# Overview

This project is a custom-built management platform developed specifically for **«Олімп Футзал» (Mykolaiv, Ukraine)**.

The system combines:

- 🌐 Public club website
- 👨‍💼 Administration panel
- 📅 Training management
- ✅ Attendance tracking
- 📊 Player statistics
- 🏆 Competitions & standings
- 📰 News management
- 🖼 Photo gallery
- 📱 Progressive Web App (PWA)
- 🔔 Push Notifications

The main goal is to replace spreadsheets and manual communication with one centralized digital platform.
