# PWA & Push Notifications

> Progressive Web App & Push Notifications Documentation  
> Version: 1.0  
> Last updated: July 2026

---

# 1. Загальна інформація

Однією з ключових можливостей системи **«Олімп Футзал»** є підтримка Progressive Web App (PWA) та Push Notifications.

Завдяки цьому гравці можуть користуватися системою як мобільним застосунком без встановлення через App Store або Google Play.

---

# 2. Основні можливості

PWA забезпечує:

- встановлення на домашній екран;
- повноекранний режим;
- швидкий запуск;
- роботу як окремого застосунку;
- Push Notifications;
- адаптацію під мобільні пристрої.

# 5. Встановлення застосунку

## Android

1. Відкрити сайт.
2. Натиснути **Install App** або **Додати на головний екран**.
3. Підтвердити встановлення.
4. Запустити застосунок.

---

## iPhone

1. Відкрити сайт у Safari.
2. Натиснути кнопку **Поділитися**.
3. Обрати **Додати на головний екран**.
4. Підтвердити встановлення.
5. Запустити застосунок.

---

# 6. Push Notifications

Push-повідомлення використовуються для:

- нових тренувань;
- нагадувань;
- зміни часу тренування;
- важливих повідомлень клубу.

---

# 7. Підписка користувача

Після першого відкриття PWA користувач може дозволити Push Notifications.

При успішній підписці:

- створюється запис у таблиці `push_subscriptions`;
- зберігається endpoint;
- зберігаються ключі шифрування;
- користувач стає доступним для розсилки повідомлень.

---

---

# 9. Голосування

Після отримання Push Notification гравець переходить до активного тренування.

Можливі відповіді:

- ✅ Буду
- ❌ Не буду
- ❓ Під питанням

Відповідь зберігається у базі даних.

---

# 10. Безпека

Для роботи Push використовується:

- HTTPS;
- Service Worker;
- VAPID Keys;
- Web Push API.

Особисті дані користувачів не передаються третім сторонам.

---

# 11. Production досвід

На момент створення документації:

- PWA встановлено реальними гравцями;
- Push Notifications успішно доставляються;
- проведено перше реальне голосування;
- система використовується під час підготовки до тренувань.

---

# 12. Типові проблеми

## Push не приходять

Можливі причини:

- користувач заборонив повідомлення;
- браузер не підтримує Push;
- Service Worker не зареєстрований;
- підписка втратила актуальність.

---

## iPhone

Для встановлення необхідно використовувати Safari.

Інші браузери можуть не підтримувати встановлення PWA.

---

## Android

У більшості випадків Chrome автоматично пропонує встановити застосунок.
