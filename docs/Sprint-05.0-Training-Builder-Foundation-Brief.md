# Sprint 05.0 — Training Builder Foundation

## Цель

Создать минимальную рабочую основу конструктора тренировочной сессии, которая использует Exercise Library как источник упражнений.

## Scope

1. Training Sessions list.
2. Create Training Session page.
3. Метаданные: название, дата, команда/возраст, цель, заметки.
4. Добавление упражнений из Exercise Library.
5. Порядок блоков тренировки.
6. Настройка длительности каждого упражнения.
7. Автоматический расчёт общего времени.
8. Сохранение как draft.
9. Повторное открытие сохранённой тренировки.
10. Empty, loading и error states.

## Acceptance Criteria

- Тренер может создать draft тренировки.
- В тренировку можно добавить минимум одно упражнение из библиотеки.
- Одно упражнение нельзя случайно добавить дважды без явного подтверждения.
- Для каждого блока отображаются код, название, категория и длительность.
- Общая длительность пересчитывается после добавления, удаления или изменения времени.
- Порядок упражнений сохраняется.
- После перезагрузки draft открывается с сохранёнными данными.
- Выход с несохранёнными изменениями защищён существующим Unsaved Changes flow.
- Интерфейс на украинском языке.

## Out of Scope

- Календарь и RSVP.
- Посещаемость.
- PWA и push-уведомления.
- AI-генерация плана.
- Session Review.
- Micro/Meso cycles.
- Tactical Board и Video Library.
- Публикация тренировки игрокам.

## Первый технический шаг

Проверить актуальный архив проекта, существующие routes для trainings и текущую схему Supabase. После этого подготовить Sprint 05.0 Foundation package без частичных вставок.
