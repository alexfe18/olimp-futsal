# Sprint 4.0.4 — Coach Workspace Navigation

Последнее обновление: 2026-08-02

## Цель

Сделать структуру админ-кабинета понятной по рабочим зонам и создать постоянную точку входа в инструменты тренера.

## Реализовано

### Робочий простір тренера

В одну группу собраны:

- `Огляд тренера` — `/admin/coach`;
- `Тренування` — `/admin/trainings`;
- `Плани тренувань` — `/admin/coach/training-plans`;
- `Бібліотека вправ` — `/admin/coach/exercises`;
- `Імпорт вправ` — `/admin/coach/exercises/import`;
- `Імпорт медіа` — `/admin/coach/exercises/media-import`.

### Другие рабочие зоны

- `Команда`: матчи, игроки, посещаемость, статистика, соревнования;
- `Комунікації`: Push, новости, галерея;
- `Система`: настройки.

### Единая конфигурация

Desktop Sidebar и мобильное меню используют один файл `admin-navigation.ts`. Это исключает расхождение пунктов и подписей между версиями навигации.

### Активные состояния

Активным становится только наиболее точный маршрут:

- `/admin/coach/exercises/import` подсвечивает `Імпорт вправ`;
- `/admin/coach/exercises/media-import` подсвечивает `Імпорт медіа`;
- `/admin/coach/exercises/create` и `/admin/coach/exercises/[id]/edit` подсвечивают `Бібліотека вправ`;
- `/admin/coach/training-plans/[id]` подсвечивает `Плани тренувань`.

## Огляд тренера

Новая страница `/admin/coach` содержит:

- Hero рабочего пространства;
- быстрые действия создания и импорта упражнения;
- карточки доступных модулей;
- текущий продуктовый приоритет `Warm-up Content Pack v1`;
- следующий этап roadmap — конструктор тренировок.

## QA checklist

1. Проверить все группы и пункты desktop sidebar.
2. Проверить те же группы в мобильном drawer.
3. Открыть `/admin/coach` и все карточки модулей.
4. Открыть Library, Create, Details и Edit — активна `Бібліотека вправ`.
5. Открыть Content Import — активен только `Імпорт вправ`.
6. Открыть Media Import — активен только `Імпорт медіа`.
7. Открыть Training Plan details — активны `Плани тренувань`.
8. Проверить закрытие мобильного меню после перехода.
9. Проверить keyboard focus и `aria-current="page"` активной ссылки.
