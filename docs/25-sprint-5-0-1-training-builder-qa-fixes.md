# Sprint 05.0.1 — Training Builder QA Fixes

## Причина

Исправления подготовлены после первого browser QA Training Builder.

## Исправлено

1. Возвращён ручной сценарий создания структуры тренировки.
   - `Додати власний блок`;
   - редактирование названия, типа, описания, длительности и заметок;
   - возможность сочетать собственные блоки и Exercise Library.
2. Удалены технические названия спринта из пользовательского Hero.
   - список: `Плани тренувань`;
   - Create/Edit: `Створення/Редагування плану тренування`.
3. Исправлено поле длительности.
   - скрыты нативные number spinners;
   - суффикс `хв` больше не перекрывает контрол;
   - поле можно временно очистить во время редактирования.
4. RPC теперь разрешает планы только из собственных блоков.
5. Счётчики и подписи используют термин `блоки`, поскольку план может содержать не только библиотечные упражнения.

## Database model

`training_plan_blocks.exercise_id` остаётся nullable:

- библиотечное упражнение — UUID записи `exercises`;
- собственный блок — `null`;
- snapshot title/description/duration/type/notes сохраняется в обоих случаях.
