# Sprint 05.0.4 — Quick View Action Visibility Fix

## Причина

Дія `Переглянути вправу` була розміщена в одному горизонтальному контейнері
разом із кнопками сортування та видалення. На частині робочих ширин контейнер
виходив за доступну ширину картки, а `overflow-hidden` приховував першу дію.
У результаті бібліотечна вправа відображалася коректно, але кнопка Quick View
була невидима.

## Зміни

- дії перегляду перенесені в окремий рядок під коротким описом вправи;
- додано постійну кнопку `Переглянути вправу`;
- додано пряме посилання `Відкрити сторінку ↗` у новій вкладці;
- службові кнопки сортування та видалення залишилися в заголовку картки;
- визначення бібліотечної вправи використовує `exerciseId` або relation `exercise.id`;
- збереження також використовує relation ID як безпечний fallback.

## Database

SQL і міграції не потрібні.
