# Sprint 4 — Exercise Import

Последнее обновление: 2026-08-02

## Цель

Добавить безопасный массовый импорт упражнений в Coach Workspace, чтобы библиотеку можно было наполнять профессиональными контент-паками без ручного создания каждой записи.

## Sprint 4.0 — Import Foundation

Реализовано:

- маршрут `/admin/coach/exercises/import`;
- кнопка `Імпортувати вправи` в Hero библиотеки;
- загрузка JSON и CSV до 5 МБ;
- JSON-шаблон и CSV-шаблон;
- поддержка JSON-массива и объекта с полем `exercises`;
- CSV с автоматическим определением `;`, `,` или tab-разделителя;
- массивы в CSV через символ `|`;
- предварительная нормализация и проверка каждой строки;
- проверка категорий, типов, форматов, сложности, интенсивности, размеров площадки, статусов, уровней библиотеки, целей и возрастных групп;
- проверка URL внешнего видео;
- поиск дубликатов по обязательному полю `code`;
- стратегии `Пропустити` и `Оновити` для дубликатов;
- создание или обновление `exercises`;
- синхронизация `exercise_goals` и `exercise_tags`;
- сохранение существующих медиа при обновлении через импорт;
- best-effort rollback для неуспешного создания или обновления;
- прогресс импорта и итоговый отчет.

## Формат данных

Обязательные поля:

- `code`;
- `title`;
- `category`;
- `exercise_type`;
- `duration_minutes`;
- `difficulty`.

Рекомендуемые поля:

- `player_format`;
- `min_players` / `max_players`;
- `intensity`;
- `field_size`;
- `description`;
- `organization`;
- `equipment`;
- `coaching_points`;
- `common_mistakes`;
- `progression`;
- `regression`;
- `alternative`;
- `load_control`;
- `age_groups`;
- `goals`;
- `tags`;
- `external_video_url`;
- `status`;
- `library_tier`;
- `source`.

В первой версии бинарные медиафайлы не входят в импорт. Обложка, схема и видеофайл существующей записи сохраняются при обновлении по коду.

## Sprint 4.0.1 — QA fixes

Исправлено после функциональной проверки импорта:

- ссылка `← До бібліотеки вправ` перенесена над Hero по общему шаблону Details/Edit;
- CSV-разделитель `|` больше не переносится отдельно от поясняющего текста;
- значения размера площадки `small`, `medium` и `large` локализованы на странице упражнения.

Проверено:

- импорт валидного JSON и CSV;
- создание новых упражнений;
- обнаружение и пропуск дубликатов;
- обновление существующих упражнений;
- ошибки строковой валидации;
- сохранение кодов, целей, тегов, возрастных групп и статусов.

## Sprint 4.0.2 — Summary Filters

Добавлено после UX-анализа сводного блока импорта:

- четыре показателя объединены в один визуальный блок по стилю статистики библиотеки;
- показатели стали кликабельными фильтрами предварительной проверки;
- строки распределяются по взаимоисключающим группам: `Готові`, `Помилки`, `Дублікати`;
- сумма `Готові + Помилки + Дублікати` равна `Усього`;
- дубликат больше не учитывается одновременно как обычная готовая строка;
- Preview показывает количество отфильтрованных строк и активную группу;
- для пустой группы добавлено отдельное empty state;
- фильтр автоматически сбрасывается на `Усього` после выбора нового файла;
- строки-дубликаты получили отдельный статус `Знайдено дублікат`.
