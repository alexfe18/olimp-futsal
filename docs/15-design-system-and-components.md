## Chip

**Путь:**  
`app/admin/coach/exercises/components/ui/Chip.tsx`

**Назначение:**  
Универсальный компактный элемент для тегов, фильтров и переключателей.

**Варианты:**

- default
- secondary
- success
- warning
- danger

**Размеры:**

- sm
- md

**Используется в:**

- CategoryChips
- TagCloud
- фильтрах библиотеки
- форме упражнения

**Когда не использовать:**  
Для основных действий формы — использовать Button.

**Статус:** Stable
