# Sprint 05.0.5 — Quick View Link Recovery & Hero Age Fix

## Причина

У частині збережених планів картка продовжувала показувати код бібліотечної вправи,
але дії `Переглянути вправу` та `Відкрити сторінку ↗` не з’являлися.
Попередній UI перевіряв лише готовий `exerciseId`. Якщо зв’язок ще не був
відновлений після завантаження бібліотеки, уся секція дій не рендерилася.

У Hero значення вікової групи використовувало `truncate`, тому значення
`U13–U14` і `Дорослі` відображалися з трьома крапками.

## Зміни

- бібліотечний блок розпізнається також за кодом вправи;
- exercise ID відновлюється за прямим ID, кодом або точним заголовком;
- кнопки перегляду завжди присутні для бібліотечного блоку;
- під час завантаження зв’язку кнопки мають видимий disabled/loading state;
- відновлений `exerciseId` записується під час наступного збереження плану;
- лічильник вибраних вправ використовує відновлений ID;
- Hero metric більше не обрізає вік і має адаптивну мінімальну ширину.
