# Sprint 05.0.3 — Exercise Quick View & Manual Block UX — QA Checklist

## Власний блок

- [ ] Натиснути `Додати власний блок`.
- [ ] Поле назви порожнє.
- [ ] Відображається placeholder `Наприклад: Розминка з мʼячем`.
- [ ] Бейдж `ВЛАСНИЙ БЛОК` відображається над формою.
- [ ] Спроба збереження з порожньою назвою показує валідацію.
- [ ] Після введення назви власний блок успішно зберігається.
- [ ] Повторне відкриття показує введену назву, а не placeholder.

## Quick View — відкриття та закриття

- [ ] Додати бібліотечну вправу до плану.
- [ ] На картці є кнопка `Переглянути вправу`.
- [ ] Кнопка відкриває праву панель без переходу зі сторінки плану.
- [ ] Сторінка під панеллю не прокручується.
- [ ] Панель закривається кнопкою `×`.
- [ ] Панель закривається кнопкою `Повернутися до плану`.
- [ ] Панель закривається клавішею `Escape`.
- [ ] Панель закривається натисканням на затемнений фон.
- [ ] Після закриття всі незбережені поля плану залишаються без змін.

## Quick View — контент

- [ ] Відображаються код, категорія, назва та опис.
- [ ] Відображаються тривалість, гравці, складність, формат, інтенсивність і майданчик.
- [ ] Відображаються вікові групи, цілі та теги.
- [ ] Відображаються організація та інвентар.
- [ ] Відображаються тренерські акценти та типові помилки.
- [ ] Відображаються ускладнення, спрощення, альтернатива й контроль навантаження.
- [ ] За наявності відображається обкладинка.
- [ ] За наявності відображається тактична схема.
- [ ] За наявності відображається локальне або зовнішнє відео.
- [ ] Для відсутніх даних показується зрозумілий empty state.

## Повна сторінка

- [ ] `Відкрити повну сторінку ↗` відкриває правильну вправу.
- [ ] Сторінка відкривається у новій вкладці.
- [ ] Поточний Training Builder залишається відкритим.
- [ ] Незбережені зміни плану не втрачаються.

## Loading та Error

- [ ] Під час завантаження показується skeleton.
- [ ] Помилка Supabase показує error state.
- [ ] Кнопка `Повторити` повторно завантажує вправу.

## Responsive

- [ ] Desktop: Drawer відкривається праворуч і не перекриває власні controls панелі.
- [ ] Tablet: усі секції читаються без горизонтального scroll.
- [ ] Mobile: Drawer займає доступну ширину, header і кнопки не обрізаються.
- [ ] Довгі назви, теги й текст коректно переносяться.

## Regression

- [ ] Додавання вправи з бібліотеки працює.
- [ ] Повторне додавання вправи показує confirmation.
- [ ] Reorder працює.
- [ ] Тривалість і нотатки редагуються.
- [ ] Ручний, бібліотечний і змішаний плани зберігаються.
- [ ] Unsaved Changes protection працює.
