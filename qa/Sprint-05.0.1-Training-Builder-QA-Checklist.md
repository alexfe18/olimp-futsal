# Sprint 05.0.1 — Training Builder QA Fixes Checklist

## 0. Precondition

- [ ] Код Sprint 05.0.1 установлен.
- [ ] Если Sprint 05.0 SQL уже выполнялся — запущен `sql/2026-08-02-training-builder-manual-blocks-fix.sql`.

## 1. Два способа создания плана

- [ ] Можно добавить упражнение из правой библиотеки.
- [ ] Можно нажать `Додати власний блок`.
- [ ] Можно создать план только из собственного блока.
- [ ] Можно создать смешанный план: собственный + библиотечный блоки.
- [ ] Собственный блок имеет badge `ВЛАСНИЙ БЛОК`.
- [ ] Редактируются название, тип, описание, длительность и заметки.
- [ ] После Save и Reload все поля собственного блока сохраняются.
- [ ] `exercise_id` собственного блока равен `null`.

## 2. Hero и production labels

- [ ] На List нет текста `Sprint 05.0`.
- [ ] List Hero показывает `Робочий простір тренера` и `Плани тренувань`.
- [ ] Create Hero показывает `Створення плану тренування`.
- [ ] Edit Hero показывает `Редагування плану тренування`.
- [ ] В Edit отображается актуальное пользовательское название плана.

## 3. Duration input

- [ ] Нативные стрелки number input не перекрывают `хв`.
- [ ] Клик по `хв` не блокирует фокус input.
- [ ] Значение можно полностью удалить и ввести заново.
- [ ] Пустое значение блокирует Save с понятной ошибкой.
- [ ] Значения 1 и 300 сохраняются.
- [ ] Значения 0 и 301 блокируют Save.
- [ ] Проверено в Chrome и Firefox на macOS.

## 4. Regression

- [ ] Добавление библиотечного упражнения работает.
- [ ] Duplicate confirmation работает.
- [ ] Reorder работает для смешанного плана.
- [ ] Remove работает для обоих типов блоков.
- [ ] Total duration считает оба типа блоков.
- [ ] Unsaved changes включает изменения ручных полей.
- [ ] Legacy custom blocks открываются и сохраняются.
