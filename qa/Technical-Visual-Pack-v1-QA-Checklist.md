# Technical Visual Pack v1 — QA Checklist

## Перевірка файлів

- [ ] У папці `covers` є рівно 15 PNG-файлів.
- [ ] Назви відповідають діапазону `TECH-001-cover.png`–`TECH-015-cover.png`.
- [ ] Кожен файл відкривається без помилок.
- [ ] Усі файли мають однакову орієнтацію 4:3.
- [ ] На зображеннях немає сторонніх написів, логотипів або водяних знаків.

## Перевірка прив’язки

Для кожної вправи:

- [ ] Код у назві файла збігається з кодом вправи.
- [ ] Обкладинка відповідає основному технічному змісту.
- [ ] Після завантаження файл показується в Edit Preview.
- [ ] Після збереження обкладинка показується у Library Card.
- [ ] Обкладинка показується у Details Hero.
- [ ] Інші медіафайли вправи не видаляються.

## Responsive QA

- [ ] Desktop: обкладинка не спотворена і правильно кадрується.
- [ ] Tablet: ключовий технічний момент залишається видимим.
- [ ] Mobile: немає горизонтального overflow.
- [ ] Якщо використовується `object-cover`, важливий об’єкт не обрізається критично.

## Regression

- [ ] Edit/Save продовжує працювати.
- [ ] Видалення або заміна обкладинки працює.
- [ ] Library filters і search не змінені.
- [ ] Import JSON/CSV не змінений.
