# Sprint 05.0.4 — Quick View Action Visibility — QA Checklist

## Бібліотечна вправа

- [ ] Під коротким описом видно кнопку `Переглянути вправу`.
- [ ] Поруч видно `Відкрити сторінку ↗`.
- [ ] Кнопки видно на desktop, tablet та mobile ширині.
- [ ] Кнопки не перекривають сортування та `Видалити`.
- [ ] `Переглянути вправу` відкриває Drawer.
- [ ] `Escape`, фон і `×` закривають Drawer.
- [ ] `Відкрити сторінку ↗` відкриває правильну вправу в новій вкладці.
- [ ] Несохранені зміни плану не втрачаються.

## Власний блок

- [ ] Дії перегляду не показуються.
- [ ] Порожнє поле назви та placeholder залишилися без змін.

## Regression

- [ ] Сортування блоків працює.
- [ ] Видалення блоків працює.
- [ ] Тривалість і нотатки редагуються.
- [ ] Збереження бібліотечного, власного та змішаного плану працює.
