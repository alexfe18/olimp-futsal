# Sprint 04.1 — Warm-up Content Pack v1: QA Checklist

## Перед імпортом

- Відкрити `/admin/coach/exercises/import`.
- Використати JSON як основний формат перевірки.
- Переконатися, що в бібліотеці немає кодів `WU-001`–`WU-015`, або свідомо обрати стратегію для дублікатів.

## Preview — чиста бібліотека

Очікується:

- `Усього`: 15
- `Готові`: 15
- `Помилки`: 0
- `Дублікати`: 0
- кнопка імпорту активна;
- кожен рядок має категорію `Розминка` і статус без помилки валідації.

## Import

- Обрати стандартну стратегію `Пропустити дублікати` для першого імпорту.
- Очікуваний результат: `Створено: 15`, `Оновлено: 0`, `Пропущено: 0`, `Помилки: 0`.

## Перевірка після імпорту

1. У Library відображаються 15 кодів `WU-001`–`WU-015`.
2. Усі вправи мають чисті назви без службових суфіксів.
3. Фільтр категорії `Розминка` повертає всі 15 вправ.
4. На Details перевірити щонайменше `WU-001`, `WU-007`, `WU-012`, `WU-015`:
   - опис і організація;
   - цілі, теги та вікові групи;
   - складність, інтенсивність, розмір майданчика;
   - джерело `Futsal Exercise Library — Warm-up Content Pack v1.0`;
   - дата й час останнього оновлення.
5. У Edit усі поля завантажуються та зберігаються без втрати даних.

## Duplicate regression

- Повторно завантажити той самий JSON.
- Очікується: `Дублікати: 15`, `Готові: 0`, `Помилки: 0`.
- Для стратегії `Пропустити`: 15 пропущено, дані не змінені.
- Для стратегії `Оновити`: 15 оновлено, назви залишаються чистими, медіа не видаляються.

## CSV parity

- Завантажити CSV після JSON-імпорту.
- Очікується 15 дублікатів без помилок парсингу.
- Масиви `age_groups`, `goals`, `tags` коректно розділені символом `|`.
