# Technical Diagram Pack v1 — QA Checklist

## Перевірка архіву

- [ ] `Technical-Diagram-Pack-v1-Import-Ready.zip` відкривається.
- [ ] В архіві рівно 15 PNG-файлів.
- [ ] Імена відповідають `TECH-001-diagram.png`–`TECH-015-diagram.png`.
- [ ] Немає дублікатів коду та типу медіа.
- [ ] Кожне зображення має розмір не менше 320×180 px.
- [ ] Розмір кожного файла менше 10 МБ.

## Media Batch Import Preview

- [ ] Усього: 15.
- [ ] Готові: 15, якщо схем ще немає.
- [ ] Помилки: 0.
- [ ] Кожен код знаходить правильну вправу.
- [ ] Тип кожного файла визначено як «Схема».
- [ ] Thumbnail preview відкривається.

## Після імпорту

Вибірково перевірити `TECH-001`, `TECH-007`, `TECH-012`, `TECH-015`:

- [ ] Схема показується на Details.
- [ ] Схема показується в Edit Preview.
- [ ] Обкладинка вправи не змінилася.
- [ ] Інші медіафайли не видалені.
- [ ] Повторний імпорт визначає файли як заміни.
- [ ] Стратегія «Пропустити» не змінює існуючу схему.
- [ ] Стратегія «Замінити» оновлює лише `diagram_image_path`.

## Responsive

- [ ] Desktop: схема читається без спотворення.
- [ ] Tablet: ключові стрілки та позиції видимі.
- [ ] Mobile: зображення масштабується без horizontal overflow.
