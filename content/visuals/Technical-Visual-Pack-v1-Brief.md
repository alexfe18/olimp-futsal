# Sprint 04.2.1 — Technical Visual Pack v1: Production Brief

Цей файл не містить готових зображень. Він фіксує єдиний задум для наступного візуального пакета.

## Єдиний стиль

- обкладинки: вертикальний спортивний кадр без тексту, темно-синя футзальна естетика, один головний технічний момент;
- схеми: чистий 2D-майданчик, однакові символи гравців, м’яча, фішок і стрілок;
- у схемі показувати лише ключову послідовність, без дублювання всього тексту вправи;
- рекомендований формат обкладинки: 4:3 або 16:9 відповідно до поточного media-компонента;
- рекомендований формат схеми: 1600×1000 PNG або SVG.
